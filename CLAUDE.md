# CLAUDE.md — marketing-assets

Este repositório é **público** e serve para alojar os ficheiros das publicações de marketing da Nortelix (email marketing, redes sociais, folhetos, marca). Os links `raw.githubusercontent.com` são usados diretamente nos emails e publicações.

Regras para quem trabalhar aqui:

1. Seguir a estrutura e as regras de nomes do `README.md` (pastas `AAAA-MM-tema`, ficheiros em minúsculas com hífenes, sem acentos).
2. Nunca colocar dados de clientes, dados pessoais, preços internos, contratos ou capturas com dados reais. Capturas de ecrã só com dados de demonstração.
3. Nunca renomear nem apagar ficheiros de campanhas já publicadas (partem os links dos emails enviados). Para uma versão nova, criar um ficheiro novo.
4. Emails: `email.html` em tabelas, estilos inline, sem JavaScript, largura 600 px, imagens com URL absoluto `https://raw.githubusercontent.com/Nortelix/marketing-assets/main/...`, ligação de cancelamento `/unsubscribe_from_list` (Email Marketing do Odoo).
5. Comprimir imagens antes de publicar (emails: idealmente < 100 KB por imagem).
6. Atualizar a tabela "Campanhas" do `README.md` sempre que se acrescenta uma campanha.
7. Commits em português, curtos, a dizer que campanha foi adicionada ou alterada.
